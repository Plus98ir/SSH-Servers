**New in this version**
- Terminal font: JetBrains Mono, clear and easy to read, with the same colors as the Windows app.
- Three views for the server list: large tiles, small tiles and list (menu ⋮).
- Side by side: turn the phone sideways (or use a tablet) with two or more sessions open, and two terminals show next to each other. Tap the other one to switch to it. The split button in the bottom bar turns it on or off.
- Updates now come from corenetbase.com, so checking and downloading works without a VPN.
- The version and build number show in the file name and in Settings.

**تغییرات این نسخه**
- فونت ترمینال: JetBrains Mono، خوانا و تمیز، با همون رنگ‌های نسخهٔ ویندوز.
- سه حالت نمایش برای لیست سرورها: کاشی بزرگ، کاشی کوچک و لیست (منوی ⋮).
- نمایش کنار هم: وقتی دو اتصال یا بیشتر بازه، گوشی رو افقی کن (یا روی تبلت) تا دو ترمینال کنار هم نشون داده بشن. برای رفتن به اون یکی، روش بزن. دکمهٔ «کنار هم» توی نوار پایین روشن یا خاموشش می‌کنه.
- آپدیت حالا از corenetbase.com میاد، پس چک کردن و دانلود بدون VPN کار می‌کنه.
- نسخه و شمارهٔ build توی اسم فایل و توی تنظیمات نشون داده می‌شه.

Download SSH-Servers.apk (or the file with the version in its name; they are the same) and install it over the old version. Your servers and settings stay.
